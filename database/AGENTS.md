# database/AGENTS.md

## 역할

DB 역할은 신규 주문 시스템의 데이터 모델, 상태값, 마이그레이션, 개인정보 저장 구조를 관리합니다.

## 책임

- 기존 Prisma 스키마와 신규 요구사항의 차이를 분석합니다.
- 주문 전체와 주문 상품을 분리합니다.
- 주문 당시 상품명, 가격, 배송지 스냅샷을 보존합니다.
- 결제, 배송, 현장 수령 상태를 독립적으로 설계합니다.
- 개인정보 암호화/접근 로그/보관 기간 요구사항을 스키마에 반영합니다.

## 작업 규칙

- 스키마 변경 전 `database/CHECKLIST.md`의 영향 범위를 갱신합니다.
- 마이그레이션 생성 후 `database/WORKLOG.md`와 기존 `database/PROGRESS.md`에 요약합니다.
- 개인정보 관련 변경은 `policy/`와 함께 검토합니다.
