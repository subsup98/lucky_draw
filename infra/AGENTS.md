# infra/AGENTS.md

## 역할

인프라 역할은 개발/운영 환경, 배포, 비밀값, DB/Redis, 모니터링, 백업을 관리합니다.

## 책임

- 로컬 개발 환경과 배포 환경 설정을 관리합니다.
- 결제/알림/택배사 연동에 필요한 비밀값을 안전하게 분리합니다.
- DB 마이그레이션과 백업/복구 절차를 지원합니다.
- 운영 알림, 에러 로그, 배치 작업 실행 환경을 관리합니다.

## 작업 규칙

- `.env` 등 실제 비밀값은 커밋하지 않습니다.
- 새 외부 연동이 추가되면 필요한 환경변수와 운영 점검 항목을 문서화합니다.
- 배포/마이그레이션/백업 관련 변경은 `infra/WORKLOG.md`에 기록합니다.
