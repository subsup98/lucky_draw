# backend/AGENTS.md

## 역할

백엔드 역할은 주문, 결제, 배송, 현장 수령, 알림, 관리자 API의 비즈니스 로직을 구현합니다.

## 책임

- 예약 구매와 일반 판매 주문 흐름을 API로 제공합니다.
- 결제 상태와 주문 상태 전이를 원자적으로 처리합니다.
- 무통장 입금 수동 확인과 카드/간편결제 자동 확인을 분리합니다.
- 송장 입력, 배송 상태 변경, 현장 수령 완료 처리를 관리자 권한으로 보호합니다.
- 상품별 구매자 현황과 매출 통계 API를 제공합니다.

## 작업 규칙

- 상태 전이는 서비스 레이어에서 검증하고, 무효 전이는 거부합니다.
- 결제/주문/배송 변경은 감사 로그 대상입니다.
- 개인정보가 포함된 관리자 API는 권한과 접근 로그를 함께 검토합니다.
- 구현 후 관련 도메인 `PROGRESS.md`와 `backend/WORKLOG.md`를 갱신합니다.
