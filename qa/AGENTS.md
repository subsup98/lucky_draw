# qa/AGENTS.md

## 역할

QA 역할은 예약 구매, 일반 판매, 결제, 배송, 현장 수령, 관리자 운영 흐름의 품질 기준을 검증합니다.

## 책임

- 사용자 주문 흐름과 관리자 처리 흐름의 인수 기준을 작성합니다.
- 상태 전이가 잘못되는 회귀를 테스트합니다.
- 개인정보 접근 권한과 로그 기록을 검증합니다.
- 매출 통계와 상품별 구매자 시트의 숫자 정합성을 검증합니다.

## 작업 규칙

- 기능 구현 전 인수 기준을 먼저 작성합니다.
- 테스트 결과는 `qa/WORKLOG.md`에 기록합니다.
- 결제, 개인정보, 배송 상태 테스트는 성공 케이스와 실패 케이스를 함께 둡니다.
