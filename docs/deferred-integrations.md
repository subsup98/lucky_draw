# 보류 외부 연동 메모

작성일: 2026-06-29

현재 도메인 주소와 실제 결제 연동을 사용할 수 없으므로, MVP 개발은 로컬/내부 URL과 Mock 결제를 기준으로 진행한다. 아래 항목은 실제 운영 도메인과 외부 계정이 준비된 뒤 재개한다.

## 1. 도메인/배포

- 사용자 사이트 도메인 확정
- 관리자 사이트 도메인 확정
- API 도메인 확정
- HTTPS/SSL 적용
- 쿠키 도메인, `COOKIE_SECURE`, CORS origin 정리
- 결제 성공/실패 redirect URL 확정
- 결제 webhook URL 확정
- 카카오 로그인 redirect URI 확정

## 2. 실제 결제

- PG사 선택 및 상점 계정 준비
- 카드 결제 승인/실패/취소 실연동
- 카카오페이 또는 간편결제 실연동
- 실결제 provider별 환경변수 등록
- webhook 서명 검증 값 등록
- 운영/테스트 결제 키 분리
- 환불 API 실연동 및 정산 확인 절차 정리

현재 대체 경로:

- 상품 주문은 `BANK_TRANSFER`, `CARD`, `KAKAO_PAY` 결제 방식을 선택할 수 있다.
- `CARD`, `KAKAO_PAY`는 실제 PG가 아니라 `mock` provider로 결제 성공 흐름을 검증한다.
- 무통장 입금은 관리자 수동 확인으로 `PAID` 전환한다.

## 3. 알림/택배사

- 카카오톡 채널 생성 후 알림톡/친구톡/SMS 발송 연동
- 이메일 발송 계정 운영값 확정
- 택배사 API 계정 준비
- 운송장 조회/배송 완료 자동 동기화 연동
- 외부 알림 실패 재시도 정책 확정

## 재개 조건

- 운영 도메인과 서브도메인 구성이 확정됨
- PG 테스트/운영 키 발급 완료
- 카카오 채널 또는 SMS 발송 계정 준비
- 택배사 연동 계정 또는 송장 업로드 운영 방식 확정
