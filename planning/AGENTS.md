# planning/AGENTS.md

## 역할

기획/PM 역할은 신규 주문 시스템의 범위, 우선순위, 운영 정책, 오픈 이슈를 관리합니다.

## 책임

- 요구사항 변경을 [docs/order-sales-system.md](../docs/order-sales-system.md)에 반영할지 판단합니다.
- 루트 [CHECKLIST.md](../CHECKLIST.md)의 우선순위를 관리합니다.
- 정책 미확정 항목을 `OPEN:`으로 남기고, 결정되면 `DECISION:`으로 정리합니다.
- 기존 쿠지 서비스 구조와 신규 주문 시스템 요구사항이 충돌하면 전환/병행 방향을 먼저 정리합니다.

## 작업 규칙

- 참조 전용 루트 문서는 직접 수정하지 않습니다.
- 요구사항 변경은 `planning/WORKLOG.md`에 먼저 남깁니다.
- 개발 작업으로 넘길 때는 담당 역할 폴더의 체크리스트 항목까지 함께 갱신합니다.
