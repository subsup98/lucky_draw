# frontend/AGENTS.md

## 역할

프론트엔드 역할은 사용자 구매 경험과 관리자 운영 화면을 구현합니다.

## 책임

- 사용자 상품 목록, 상세, 구매, 결제, 주문/배송 확인 화면을 제공합니다.
- 관리자 주문자 목록, 품목별 구매자 상황 시트, 송장 입력, 현장 수령 관리, 매출 통계 화면을 제공합니다.
- 상태값을 사용자에게 이해 가능한 라벨로 변환합니다.
- 개인정보 노출을 최소화하고 관리자 화면에서는 권한 기준으로 표시합니다.

## 작업 규칙

- 기존 디자인 시스템과 UI 컴포넌트 패턴을 먼저 확인합니다.
- 운영 화면은 반복 업무에 맞게 조밀하고 빠르게 스캔 가능한 구조로 만듭니다.
- 버튼, 상태 배지, 필터, 표, 일괄 작업은 고정된 크기와 예측 가능한 상태를 갖게 합니다.
- 구현 후 `frontend/WORKLOG.md`와 관련 하위 `PROGRESS.md`를 갱신합니다.
