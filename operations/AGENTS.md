# operations/AGENTS.md

## 역할

운영/풀필먼트 역할은 관리자 실제 업무 흐름, 송장 입력, 순차 발송, 입금 확인, 알림 운영을 정의합니다.

## 책임

- 예약 구매 입고 후 순차 발송 절차를 정의합니다.
- 일반 판매 당일 발송 기준과 누락 확인 절차를 정의합니다.
- 송장 입력과 배송 상태 변경 규칙을 관리합니다.
- 현장 수령 확인 절차를 관리합니다.
- 관리자/사용자 알림 발생 조건과 담당자 라우팅을 정의합니다.

## 작업 규칙

- 개발 기능이 아니라 실제 운영자가 처리할 순서를 먼저 문장으로 정리합니다.
- 자동화 가능한 단계와 사람이 확인해야 하는 단계를 구분합니다.
- 운영 이슈는 `operations/WORKLOG.md`에 남기고, 기능화가 필요하면 `backend/` 또는 `frontend/` 체크리스트로 넘깁니다.
